# RAIYONS Naruto Adventure

A colorful browser-based Naruto-inspired platform adventure. Collect coins, avoid roaming enemies, and reach the finish flag!

## Run the game

Open `index.html` in a modern browser. No build step or dependencies are required. If your browser restricts local files, serve this directory with any static file server.

## Controls

- Move: **Left/Right Arrow** or **A/D**
- Jump: **Up Arrow**, **W**, **Space**, or the on-screen jump button
- Pause/resume: **Esc** or the pause button
- Touch devices: use the on-screen movement buttons

The best score is saved in browser local storage on the current device. The game still works if browser storage is unavailable.

## Project files

- `index.html` — accessible game layout and controls
- `style.css` — responsive styling and menu animations
- `script.js` — canvas rendering, physics, and game logic
